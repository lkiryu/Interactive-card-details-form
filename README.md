# Interactive Card Details Form

Aplicação desenvolvida com **React, TypeScript e Tailwind CSS** que simula o preenchimento de um formulário de cartão de crédito com visualização em tempo real.

## Funcionalidades

- Visualização dinâmica dos dados do cartão enquanto o formulário é preenchido.
- Validação dos campos utilizando React Hook Form e Zod.
- Formatação e validação do número do cartão, validade e CVC.
- Exibição de uma tela de confirmação após o envio.
- Gerenciamento de estado compartilhado por meio de Context API.

## Tecnologias utilizadas

- React
- TypeScript
- Tailwind CSS
- React Hook Form
- Zod
- Vite

## Como executar o projeto

1. Clone o repositório:

   ```bash
   git clone https://github.com/lkiryu/Interactive-card-details-form.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd Interactive-card-details-form
   ```

3. Instale as dependências:

   ```bash
   npm install
   ```

4. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

## Objetivo do projeto

Este projeto foi desenvolvido para praticar a criação de formulários interativos, validação de dados, gerenciamento de estado e construção de interfaces responsivas utilizando React e TypeScript.
